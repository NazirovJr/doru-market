# Настройка dsh под исполнителя

Копии файлов, которые живут вне репозитория. Нужны, чтобы восстановить настройку после
переустановки dsh. Зачем каждый — в `../ANALYSIS-2026-09-19.md` §4.9.

| Файл здесь | Куда класть |
|---|---|
| `executor.agent.cordis.yml` | `~/.dsh/.agent-presets/executor/agent.cordis.yml` |
| `profile-web.cordis.patch.yml` | `~/.dsh/profiles/web/cordis.patch.yml` |

Пресет `executor` — копия шипованного `standard` без `tool-goal` (цель закрывает человек) и без
делегирования, навыков и веба. Патч профиля снижает предел раундов цели с 256 до 20.

После правки любого из них dsh нужно перезапустить. Пресет выбирается фишкой на экране новой
сессии, рядом с выбором рабочей папки; в шапке сессии видно, какой пресет запущен.

Пресет собран копированием из `apps/cli/config/agent-presets/standard/agent.cordis.yml` той версии
dsh, что стоит сейчас. После обновления dsh пересобрать копированием заново, а не правкой этого
файла: в `standard` меняются строки, которых здесь ещё нет.

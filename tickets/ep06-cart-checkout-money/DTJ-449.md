## Задача

`checkout.use-case.ts` и `retry-payment.use-case.ts` передают банку описание счёта `DoruTJ order N` — для
White-Label тенанта клиент увидит в банковском приложении чужой бренд. Найдено ESLint-правилом запрета хардкода
бренда (DTJ-060, 2026-09-29), оба места в исключениях правила с TODO.

## Что сделать

Название бренда тенанта для описания — из брендинга тенанта (DTJ-059), полученное ДО открытия транзакции группы
checkout (иначе self-deadlock пула, см. checkout-race-conditions). Убрать оба исключения из `eslint.config.mjs`.

## Критерии приёмки

1. Given заказ в тенанте sifat, Then описание счёта содержит «Sifat Pharmacy», не «DoruTJ».
2. Нагрузочный тест checkout-race-conditions зелёный; исключения правила для этих файлов удалены.

## Задача
HTTP-граница карты аптек — тонкий контроллер, парсящий строку `bbox` в структуру, вызывающий use
case (DTJ-196) и маппящий `BboxTooLargeError` в корректный HTTP-код.

## Технический контекст
Слой `presentation`, зависит только от `application` (`GetPharmacyMapPinsUseCase`, DTJ-196).
Валидация формата `bbox`/`medicineId` — через `PharmacyMapQuerySchema` (`packages/contracts/src/
pharmacies-map.ts`, DTJ-194).

## Что сделать
1. `GET /api/v1/pharmacies/map?bbox=<lonMin,latMin,lonMax,latMax>&medicineId=<uuid?>` — query
   валидируется `PharmacyMapQuerySchema` (формат — 4 числа, корректный порядок), затем строка `bbox`
   парсится в `Bbox`-объект (`lonMin < lonMax`, `latMin < latMax` — given нарушено, `400
   VALIDATION_ERROR details.field='bbox'` уже на этом шаге, до вызова use case — вырожденный
   прямоугольник не должен доходить до расчёта площади).
2. Вызвать `GetPharmacyMapPinsUseCase.execute()`, перехватить `BboxTooLargeError` → `400
   VALIDATION_ERROR details.field='bbox'` (`SRS-CAT-054`).
3. Замапить `MapPinDto[]` → JSON через `pharmacy-map.mapper.ts` — форма ответа по
   `PharmacyMapResponseSchema` (DTJ-194).
4. Тенант резолвится стандартным guard'ом (EP-02), не вручную.

## Критерии приёмки
1. Given `bbox`, покрывающий площадь `> 2500 км²`, When запрос, Then `400 VALIDATION_ERROR
   details.field='bbox'` (`TC-CAT-024`).
2. Given `bbox` с `lonMin > lonMax` (некорректный порядок координат), When запрос, Then `400
   VALIDATION_ERROR details.field='bbox'` ДО вызова `GetPharmacyMapPinsUseCase` (проверяется через
   мок use case — НЕ вызван).
3. Given валидный `bbox` в пределах лимита и валидный `medicineId`, When запрос, Then `200` с
   массивом пинов, у которых `offer` заполнено для аптек с остатком.
4. Given валидный `bbox`, `medicineId` НЕ передан, When запрос, Then `200`, у всех пинов
   `offer: null`.

## Тест-план
E2E/интеграционные (supertest): валидация формата `bbox` (число полей, порядок координат,
нечисловые значения), проброс ошибки превышения площади в `400`, happy path с/без `medicineId`.
Порог покрытия `presentation/` ≥ 70 %.

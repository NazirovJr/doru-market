## Задача

Плашка «Сэкономьте N сомони» — единственное признанное защитимое отличие продукта
(`04-SCOPE-DECISION-PIVOT.md` §2) и одновременно юридически чувствительное заявление об
эквивалентности препаратов. Ошибка здесь — не баг интерфейса, а риск ложной медицинской
рекомендации. Это авторитетное, единственное место в кодовой базе, где принимается финальное решение
«B является аналогом A» — SQL-предфильтры (DTJ-100) лишь сужают выборку, окончательное решение
всегда здесь.

## Технический контекст

`modules/catalog/domain/services/analog-equivalence.service.ts` — ЧИСТАЯ функция без I/O
(SRS-CAT-042), читает только уже загруженные в память агрегаты `Medicine` (включая
`MedicineSubstance[]`, DTJ-093), не делает запросов к БД. Юнит-тестируется без БД, порог покрытия
domain ≥90% (`02` §6).

## Что сделать

1. `domain/services/analog-equivalence.service.ts` — `class AnalogEquivalenceService`:
   ```typescript
   isAnalog(a: Medicine, b: Medicine): boolean {
     if (a.id === b.id) return false;
     if (!this.hasIdenticalSubstanceSet(a, b)) return false;
     if (!a.dosageForm.isEquivalentTo(b.dosageForm)) return false;   // diagonal-only, DTJ-090
     return this.hasEquivalentStrengthForEverySubstance(a, b);
   }
   ```
2. `hasIdenticalSubstanceSet(a, b): boolean` (приватный метод) — множества `substanceId` ИДЕНТИЧНЫ
   (не подмножество/пересечение, SRS-CAT-031/SRS-DOM-158): сравнение через отсортированные массивы
   `substanceId`, длина ОБЯЗАНА совпадать ДО сравнения содержимого (частичное пересечение — например,
   парацетамол+кофеин vs парацетамол+кодеин — сразу `false`, TC-DOM-014/TC-CAT-030).
3. `hasEquivalentStrengthForEverySubstance(a, b): boolean` (приватный метод) — для КАЖДОГО общего
   `substanceId` берёт `MedicineSubstance.strengthValue/strengthUnit` из обеих сторон, строит
   `Dosage` (domain-kernel, DTJ-090) и вызывает `Dosage.isEquivalentTo()` (SRS-DOM-078) — ВСЕ
   вещества обязаны быть эквивалентны, ЛЮБОЕ несовпадение → `false` целиком (`Array.every`, не
   частичное большинство).
4. НЕ реализовывать суммарную/кратностную эквивалентность (`500мг×2 ≟ 1000мг×1`) — явно
   задокументировать комментарием со ссылкой на SRS-CAT-035 ПОЧЕМУ это намеренное ограничение, не
   недосмотр (домен не имеет понятия «количество единиц в приёме», это относится к посологии, не к
   `Dosage` товара).
5. Комментарий-предупреждение на уровне класса, ссылающийся на SRS-CAT-033: диагональная матрица
   форм (tablet≠capsule) — дизайн-решение, смягчение требует ADR на имя архитектора
   (`03-ARCHITECT-DECISIONS.md` преамбула), правка этого файла в обход ADR — блокирующее замечание
   ревью.

## Критерии приёмки

- Given A — `tablet, 500 мг`, B — `tablet, 1000 мг`, то же вещество, When `isAnalog(A, B)`, Then
  `false` — TC-CAT-010 (обязательный regression, суммарная кратность НЕ учитывается ни в каком виде).
- Given A — `500 mcg`, B — `0.5 mg`, та же форма, то же вещество, When `isAnalog(A, B)`, Then `true`
  — TC-CAT-011 (конвертация единиц массы).
- Given A — `10 mg`, B — `10 ml`, та же форма, When `isAnalog(A, B)`, Then `false` — TC-CAT-012
  (масса и объём не сравниваются, независимо от числового совпадения).
- Given A — `tablet`, B — `capsule`, идентичное вещество+дозировка, When `isAnalog(A, B)`, Then
  `false` — TC-CAT-008.
- Given A — `syrup`, B — `injection`, идентичное вещество+дозировка, When `isAnalog(A, B)`, Then
  `false` — TC-CAT-009.
- Given A — `{парацетамол 500мг}`, B — `{парацетамол 500мг, кофеин 50мг}`, When `isAnalog(A, B)`,
  Then `false` (частичное пересечение — TC-DOM-014).

- Все 6 сценариев из «Критериев приёмки» дословно как отдельные тест-кейсы (имена кейсов совпадают с

- Дополнительно: `isAnalog(A, A)` (тот же `id`) → `false` (защита от самосравнения); комбинированный
  препарат с 3 веществами, где 2 совпадают, а 3-е отсутствует у второго — `false`; идентичные
  препараты по всем трём критериям (позитивный кейс) → `true`.

Интеграционных/E2E тестов не требуется — сервис не имеет I/O.

## Риски и подводные камни

- Народная интуиция «таблетка и капсула — по сути одно и то же» — частая точка споров на код-ревью
  и с продактом; правило диагональной матрицы — осознанное решение (SRS-CAT-033), не обсуждается в
  рамках этого тикета без отдельного ADR.
- `Dosage.isEquivalentTo()` уже покрыт unit-тестами в DTJ-090 на уровне VO — этот тикет не дублирует
  те тесты, а тестирует ОРКЕСТРАЦИЮ (множество веществ + форма + дозировка вместе), не саму
  арифметику конвертации.

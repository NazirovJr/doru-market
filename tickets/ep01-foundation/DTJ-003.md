## Задача

`apps/web` — покупательское SPA (React 19 + Vite 7), первый и единственный в R1 фронтенд-каркас,
который EP-01 обязан создать (per `tickets/00-EPICS.md` «Обязательные сквозные тикеты»: «Scaffolding
apps/web (shell, роутер, auth-экран) — EP-01 — Первый фронтовый потребитель Auth»). Этот тикет создаёт
только каркас — точку входа, роутер, API-клиент с интерсепторами; сам экран `/login` — отдельный тикет
(DTJ-028), т.к. он появляется только после того, как backend-эндпоинты OTP готовы.

## Технический контекст

`01-TECH-BASELINE.md` §Frontend: `react`/`react-dom ^19.2.0`, `vite ^7.3.6` + `@tailwindcss/vite`
(CSS-first Tailwind v4, БЕЗ `tailwind.config.js`), `@tanstack/react-query ^5.102.6`,
`react-router ^7.18.2` (declarative mode), `zustand ^5.0.15`. `02-CLEAN-ARCHITECTURE-AND-CODE.md` §5 —
структура `app/pages/features/entities/shared`, правило зависимостей строго вниз, горизонтальные
импорты `feature-a → feature-b` запрещены. Этот тикет создаёт только `app/` и `shared/api`+`shared/config`
— `pages/`/`features/`/`entities/` заводятся по мере появления реальных экранов (первый — DTJ-028).

`SRS-UX-027`: переключатель языка (`tj`/`ru`/`en`) обязан быть доступен на ВСЕХ экранах без
авторизации — этот тикет не рисует сам переключатель (компонент — `packages/ui`, вне зоны EP-01), но
обязан зарезервировать место в layout-шаблоне (`app/layout.tsx`) и провайдер локали
(`LocaleProvider`, читает/пишет `localStorage` + дефолт `tj`), чтобы `packages/i18n`
(параллельный минимальный бутстрап, `tickets/00-EPICS.md` «Волна 1») подключался без переделки шелла.

## Что сделать

1. `apps/web/package.json`, `vite.config.ts` (`@vitejs/plugin-react` + `@tailwindcss/vite`),
   `tsconfig.json` (расширяет `tsconfig.base.json`).
2. `apps/web/src/app/main.tsx`: точка входа, `QueryClientProvider` (`@tanstack/react-query`,
   `defaultOptions.queries.retry` конфигурируемо), `RouterProvider`.
3. `apps/web/src/app/router.tsx`: `createBrowserRouter` (react-router v7 declarative), маршруты
   `/` (плейсхолдер-заглушка «скоро») — реальные экраны каталога/поиска не входят в этот тикет (другие
   эпики); маршрут `/login` зарезервирован как `lazy()`-заглушка, реальный компонент подключит DTJ-028.
4. `apps/web/src/app/layout.tsx`: корневой layout — шапка с плейсхолдером `BrandLogo` (текстовый
   placeholder `[ Бренд ]`, реальный компонент — `packages/ui`, EP-18) и местом под
   `LanguageSwitcher` (тоже плейсхолдер до готовности `packages/ui`).
5. `apps/web/src/app/providers/locale-provider.tsx`: React-контекст `locale: 'tj'|'ru'|'en'`,
   персистентность в `localStorage` (ключ `dorutj.locale`), дефолт `tj` (`SRS-UX-027`).
6. `apps/web/src/shared/api/http-client.ts`: тонкая обёртка над `fetch` (не `axios` —
   `02-CLEAN-ARCHITECTURE-AND-CODE.md` §5 «`fetch`/`axios` внутри компонента запрещён — только через
   слой `api`», этот файл и есть тот единственный слой): базовый URL из ENV, интерсептор добавляет
   `Authorization: Bearer <access>` из `authStore` (Zustand, заводится в DTJ-024 вместе с реальным
   логином — здесь `authStore` заводится с пустым состоянием `{ accessToken: null }`), интерсептор
   401 → `TOKEN_EXPIRED` вызывает `refresh` ровно один раз (эндпоинт появится в DTJ-025), при повторном
   401 — редирект на `/login` (сам обработчик редиректа — заглушка `console.warn`
   до готовности реального `/login`, замена — не блокирующий follow-up DTJ-028).
7. `apps/web/src/shared/config/env.ts`: чтение `import.meta.env.VITE_API_BASE_URL` с валидацией
   наличия на старте (аналог `env.schema.ts` backend-тикетов, но клиентский — `throw` при сборке dev,
   не при рантайме прод-бандла).
8. `apps/web/.env.example`.

## Критерии приёмки

1. **Given** `pnpm --filter @dorutj/web dev`, **When** приложение открыто в браузере, **Then**
   рендерится layout с плейсхолдерами бренда/языка без ошибок в консоли.
2. **Given** `authStore.accessToken = null`, **When** `httpClient` делает запрос к защищённому
   эндпоинту-заглушке и получает `401`, **Then** интерсептор пытается `refresh` ровно один раз (не
   зацикливается) — проверяется мок-сервером в тесте.
3. **Негативный:** **Given** `VITE_API_BASE_URL` не задан, **When** `pnpm --filter @dorutj/web build`,
   **Then** сборка падает с понятной ошибкой на этапе `env.ts`, а не тихо шлёт запросы на `undefined`.

## Тест-план

- Unit (Vitest + Testing Library): `LocaleProvider` — дефолт `tj`, персистентность в `localStorage`;
  `http-client` — добавление `Authorization`-заголовка при наличии токена, ЕДИНСТВЕННЫЙ повторный
  `refresh`-вызов на серию из двух подряд `401` (не бесконечный цикл — зеркалирует правило
  `SRS-API-035` для мобильных клиентов, но на вебе).
- Integration: рендер `app/layout.tsx` без падений (`@testing-library/react` smoke-тест).
- Порог покрытия `shared/`/`app/` — ≥70% (не `domain`/`application`, фронтенд не размечен этим порогом
  явно `02-CLEAN-ARCHITECTURE-AND-CODE.md` §6.4, но следовать той же дисциплине).

## Риски и подводные камни

- `packages/ui`/`packages/i18n` — не в зоне EP-01 (кроме `packages/i18n`, минимальный скелет которого
  заводит отдельный тикет DTJ-004 этого же эпика, но `packages/ui` — целиком EP-18). Если минимальный
  бутстрап `packages/ui` (`tickets/00-EPICS.md` «Волна 1», параллельный меньший состав) отстаёт от
  этого тикета, layout остаётся на текстовых плейсхолдерах дольше ожидаемого — не блокирует приёмку
  ЭТОГО тикета (плейсхолдер — валидное временное состояние), но блокирует DTJ-028 (реальный экран
  логина использует компоненты `packages/ui`).
- `authStore`/`http-client` создаются здесь «пустыми» (нет ни одного реального защищённого эндпоинта
  для интеграционной проверки за пределами мок-сервера) — риск, что поведение 401→refresh не будет
  реально проверено до DTJ-024/025; тест-план явно требует мок-сервер (`msw` или аналог), не реальный
  backend, чтобы не блокироваться на готовности auth-эндпоинтов.
- Файл `apps/web/package.json` — barrel (D-27): правится ТОЛЬКО добавлением строки, перечитывать перед правкой, слияние конфликтов — за архитектором.
- Файл `apps/web/tsconfig.json` — barrel (D-27): правится ТОЛЬКО добавлением строки, перечитывать перед правкой, слияние конфликтов — за архитектором.

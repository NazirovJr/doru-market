## Задача

E2E DTJ-418 (2026-09-28) показал, что CUJ-1 в apps/web нельзя пройти кликами:
1. Карточка результата поиска (`search-result-card.tsx`) не ведёт на `/medicines/:id`.
2. Кнопки «В корзину» нет ни в поиске, ни на карточке товара (стаб с TODO(EP-04/EP-07)), ни у аналогов.
3. В интерфейсе нет ни одной ссылки на `/cart`.
4. `auth-store.ts` обещает `hydrate()`/refresh при старте, но вызова нет: после перезагрузки
   вошедший пользователь теряет сессию и видит гостевую корзину.
5. `GET /medicines/search` вызывается без координат — «нет в наличии рядом» (SRS-CAT-045) недостижимо.

## Что сделать

Закрыть пункты 1–5 компонентами `@dorutj/ui`, строки — i18n tj/ru/en, add-to-cart — существующий
`POST /api/v1/cart/items` (гость — `X-Cart-Session-Token`), координаты — из геолокации браузера
с понятным отказом/ручным выбором.

## Критерии приёмки

1. Given гость на `/`, When поиск → клик по результату → «В корзину» → иконка корзины в шапке,
   Then товар в `/cart` — всё кликами, без прямых URL.
2. Given вошедший пользователь, When перезагрузка страницы, Then сессия восстановлена, корзина его.
3. Given разрешена геолокация, Then позиции без остатка рядом приглушены (SRS-CAT-045).

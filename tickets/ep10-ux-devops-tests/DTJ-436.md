## Задача

E2E CUJ-12 (DTJ-422) вживую нашёл три дефекта apps/web (2026-09-27):
1. `apps/web/src/app/layout.tsx` рендерит на каждом неавторизованном экране захардкоженный `'[ Бренд ]'`
   с `TODO(EP-18)` без номера тикета; смена локали на него не влияет. apps/pharmacy и apps/admin уже
   используют `BrandLogo`/`LanguageSwitcher` из `@dorutj/ui`.
2. Форма `/pharmacy-application` (`features/onboarding-application/pharmacy-application-form.tsx`)
   целиком на русском хардкоде — ни одного `t()`.
3. `formatNumber`/`formatPluralized` из `packages/i18n` (DTJ-402) не используются ни одним экраном.

## Что сделать

1. Шапка apps/web — `BrandLogo` и `LanguageSwitcher` из `@dorutj/ui` по образцу apps/pharmacy,
   название бренда — `t('brand.name')`/брендинг тенанта. Убрать `[ Бренд ]` и TODO.
2. Форма заявки аптеки — все строки через i18n (tj/ru/en), значения полей переживают смену локали.
3. Количества (корзина, карточка товара, остаток) — через `formatPluralized`/`formatNumber` с локалью провайдера.

## Критерии приёмки

1. Given apps/web на tj, When переключить на ru, Then не остаётся ни одной строки интерфейса без
   изменения (кроме бренда и кодов локали) — спека CUJ-12 DTJ-422 зелёная вживую.
2. Given форма заявки с введёнными данными, When сменить локаль, Then метки переведены, значения сохранены.
3. Given 1/2/5 упаковок, When открыта корзина на ru, Then «1 упаковка / 2 упаковки / 5 упаковок».

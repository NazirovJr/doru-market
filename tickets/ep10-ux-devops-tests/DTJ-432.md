## Задача

`@fastify/rate-limit` стоит в зависимостях `apps/api`, но нигде не зарегистрирован: SRS-API-012/013
не реализованы, публичные маршруты открыты для флуда. OTP защищён собственным лимитером модуля auth
(§3.1 спеки 12) — его не трогать. Найдено при приёмке DTJ-379 (2026-09-25).

## Технический контекст

Спека уже задаёт поведение (`docs/spec/12-api-conventions-auth-tenancy.md` SRS-API-012/013,
`20-module-catalog-search.md` SRS-CAT-057):
- два уровня: глобальный дефолт + переопределение на маршруте декоратором `@RateLimit({ max,
  windowSec, keyBy })`;
- дефолты из ENV: `RATE_LIMIT_ANON_PER_MIN = 100` (ключ IP), `RATE_LIMIT_USER_PER_MIN = 300`
  (ключ `userId`), `RATE_LIMIT_1C_BATCH_PER_MIN = 20` для `POST /inventory/batch-update` (ключ
  `pharmacyId`) — точные значения и остальные строки таблицы бери из спеки;
- поиск и подсказки — под общим анонимным лимитом, отдельного строже нет (SRS-CAT-057);
- ответ 429 — конверт `{ error: { code: 'RATE_LIMITED' } }` (`ErrorCode.RATE_LIMITED` уже в
  contracts) + `Retry-After`; заголовки `X-RateLimit-Limit/Remaining/Reset` — на КАЖДОМ ответе
  лимитируемого маршрута.
Плагины регистрируются в `main.ts` (`registerTransportSecurity`). Хранилище — Redis (приложение
масштабируется горизонтально).

## Что сделать

1. Конфиг лимитов из ENV (`env.schema.ts`), без магических чисел в коде.
2. Регистрация плагина с Redis-хранилищем; ключ — `userId` для аутентифицированного запроса, иначе
   IP с учётом доверенного прокси (nginx из `infra/docker`).
3. Декоратор `@RateLimit` для переопределения на маршруте; применить к `batch-update` по спеке.
4. `/health`, `/ready`, внутренние маршруты (`/internal/*`) и вебхук банка (HMAC) — вне лимита.
5. 429 через общий фильтр исключений в конверте проекта.

## Критерии приёмки

1. **Given** анонимный лимит N, **When** с одного IP N+1 запросов к поиску, **Then** последний —
   `429 RATE_LIMITED` с `Retry-After`; на предыдущих — заголовки `X-RateLimit-*`.
2. **Given** два аутентифицированных пользователя за одним IP, **When** каждый делает N запросов,
   **Then** оба укладываются в свой пользовательский лимит.
3. **Given** превышен лимит, **When** `/health`, **Then** 200.
4. **Given** запросы OTP, **When** выполняются, **Then** поведение лимитера auth не изменилось.

## Тест-план

- Интеграционный на реальном Redis (в тестовом окружении — порт 6380) с маленькими лимитами из ENV.

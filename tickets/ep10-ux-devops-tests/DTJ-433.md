## Задача

Дизайн-система `packages/ui` (DTJ-401..411) влита в development, но кабинет аптеки её не использует:
ноль импортов `@dorutj/ui`, свои простые компоненты, язык зашит (`useT('tj')` во всех экранах),
нет общей оболочки с навигацией. Найдено владельцем при ручной проверке кабинета (2026-09-26).

## Что сделать

1. Оболочка кабинета: шапка (название аптеки/сети, `LanguageSwitcher` из `packages/ui`, выход),
   навигация между разделами (очередь заказов, остатки, история синхронизации, возвраты) —
   компонентами `packages/ui` (Tabs/навигация DTJ-408). Разделы видны по роли.
2. Локаль: провайдер локали на уровне приложения (резолвинг из `@dorutj/i18n`, DTJ-402), выбор
   сохраняется между сессиями; все экраны берут локаль из провайдера, а не `useT('tj')`.
3. Экраны `auth`, `inventory-*`, `returns`, `sync-history`, `pages/*` — перевести на примитивы
   `packages/ui` (Button, Input, Card, Badge, CursorTable, EmptyState/ErrorState, Toast, FileDropzone).
   Свои дублирующие компоненты, которые заменены, удалить.
4. `features/order-fulfillment/**` не переделывать — им владеет DTJ-312 (параллельно). Разрешено
   только заменить там вызовы `useT('tj')` на локаль провайдера.
5. Цвета — только токены/CSS-переменные бренда, строки — i18n tj/ru/en.

## Критерии приёмки

1. Given пользователь выбрал «RU» в шапке, When он переходит между разделами и перезагружает
   страницу, Then интерфейс остаётся на русском.
2. Given фармацевт, When открыт кабинет, Then в навигации нет разделов, недоступных его роли.
3. Given экран остатков/возвратов/истории, When идёт загрузка, пусто или ошибка, Then показаны
   Skeleton/EmptyState/ErrorState из `packages/ui`, а не самописные блоки.
4. В `apps/pharmacy/src` вне `order-fulfillment` не осталось `useT('tj')` и самописных аналогов
   компонентов `packages/ui` (проверка grep в отчёте).

## Тест-план

Компонентные тесты оболочки (переключение языка, скрытие разделов по роли), обновление
существующих спек экранов, i18n-smoke новых ключей в трёх локалях.

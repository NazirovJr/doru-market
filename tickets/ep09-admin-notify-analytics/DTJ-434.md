## Задача

Админка непригодна вживую: нет экрана входа (роль читается из `localStorage`, куда токен никто не
кладёт), `httpRequest` не отправляет `Authorization` — каждый запрос получает 401, у оболочки нет
меню и стартовой страницы, стили `packages/ui` не подключены. Все экраны EP-15/17 проходили тесты
только на мок-fetch. Найдено владельцем при ручной проверке (2026-09-27).

## Что сделать

1. Вход по OTP для ролей super_admin / pharmacy_admin / support_agent — тот же поток, что в
   `apps/pharmacy` (DTJ-166/433: PhoneInput, OtpInput, хранилище сессии). Переиспользуй подход,
   не копируй файлы между приложениями без нужды; общее — кандидат в `packages/*` (обоснуй в отчёте).
   Роль без доступа к админке (customer/pharmacist/courier) — понятный отказ, не пустой экран.
2. `httpRequest` отправляет `Authorization: Bearer`, на 401 — одна попытка refresh, затем выход
   на экран входа. Роутер строится после входа (роль из сессии, а не из модуля при загрузке).
3. Оболочка: шапка (имя, `LanguageSwitcher`, выход), боковое меню из `role-routes.ts` по роли,
   стартовая страница `/` → первый раздел роли. Провайдер локали — по образцу DTJ-433; вызовы
   `useT('ru')`/`useT('tj')` в экранах заменить на локаль провайдера.
4. Подключить стили/токены `packages/ui` (как `apps/pharmacy/src/app/App.tsx`), убрать временные
   токены из `index.html`, если они есть в `packages/ui`.

## Критерии приёмки

1. Given super_admin вошёл по OTP, When открыт `/`, Then видно меню разделов super_admin и первый
   раздел загружен данными с API (не 401).
2. Given pharmacy_admin, When открыт `/admin/my-pharmacies`, Then список точек сети с API.
3. Given access-токен истёк, When экран делает запрос, Then refresh и повтор запроса без выхода.
4. Given pharmacist пытается войти, Then сообщение «нет доступа к админке», сессия не сохранена.

## Тест-план

Компонентные тесты входа, оболочки (меню по ролям), http-client (Bearer, refresh на 401); живой
вход против dev-API на :3000 (демо: +992184539998 pharmacy_admin, super_admin — завести в dev-БД
через координатора).

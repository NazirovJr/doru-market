# D-13. Каталог 8 000+ позиций за Спринт 2 — нереалистично
**Решение:** критерий приёмки меняется. Обязательно: (а) seed ≥ 300 курированных позиций
с корректными связями МНН и веществами; (б) работающий конвейер наполнения «снизу вверх»
из выгрузок + очередь ручной модерации; (в) импорт справочника из CSV одной командой.
Абсолютное число 8 000 в критерии готовности продукта **не фигурирует**.

# D-06. Матчинг товара по штрихкоду ненадёжен
**Решение:** обязателен **composite-матчинг** в порядке: (1) валидация EAN-13 по контрольной цифре
и префиксу — префикс `2` признаётся внутренним кодом продавца и НЕ используется как глобальный ключ;
(2) точное совпадение по `(chain_id, internal_sku)`; (3) trigram-fuzzy по
`(trade_name, dosage_form, dosage_strength, manufacturer_name)` с порогом; (4) непокрытое —
в очередь ручной модерации `catalog_match_queue`. Прямой `WHERE barcode = ?` как единственный
способ идентификации — **дефект**.

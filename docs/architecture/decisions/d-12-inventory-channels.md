# D-12. Каналы поступления остатков
**Решение:** REST push (1С), импорт Excel/CSV, ручной ввод в веб-кабинете аптеки и CommerceML —
**равноправные каналы**, все проходят через ОДИН use case `IngestInventoryBatchUseCase`.
Аптека без автоматизации обязана быть полноценным участником платформы с первого дня.

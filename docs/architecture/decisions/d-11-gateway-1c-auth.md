# D-11. 1С-шлюз: обязательный mTLS (ТЗ) vs API-ключ (research)
**Решение:** основной механизм — **API-ключ** (`X-Pharmacy-API-Key`, хранится как argon2-хеш)
**плюс обязательная HMAC-SHA256 подпись тела** с `timestamp` и `nonce` (анти-replay, окно 5 минут).
mTLS — опциональный флаг per-pharmacy (`require_mtls`), включается для крупных сетей.
Обязательный mTLS для 500+ разнородных клиентов операционно нереализуем.

# D-01. Бренд «DoruTJ» vs существующий `doru.tj` — НЕ БЛОКИРУЕТ РАЗРАБОТКУ
**Решение:** разработка продолжается под рабочим именем `DoruTJ`. Название, домен, логотип и палитра
**выносятся в конфигурацию** нейтрального тенанта (`tenants` строка `neutral` + ENV `BRAND_*`).
**Запрещено** хардкодить строку «DoruTJ» где-либо в коде и UI — только i18n-ключ `brand.name`
и токен `--brand-logo`. Ребрендинг обязан стоить *изменение конфига и ассетов, ноль правок кода*.
Юридическая проверка товарного знака — коммерческое решение заказчика, вынесено в отчёт.
**Тест-требование:** e2e-тест меняет `BRAND_NAME` и проверяет, что нигде не осталось старой строки.

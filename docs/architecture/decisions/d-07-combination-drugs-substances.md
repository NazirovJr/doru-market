# D-07. Комбинированные препараты не укладываются в `inn_name` (одно поле)
**Решение:** схема ТЗ расширяется без слома совместимости:
- `medicines.inn_name` **остаётся** (денормализованная строка для отображения и поиска);
- добавляются `substances` и `medicine_substances(medicine_id, substance_id, strength_value, strength_unit)`.
**Аналогом** считается препарат с *идентичным множеством действующих веществ* + совместимой
лекарственной формой + эквивалентной дозировкой. Совпадение по одной строке `inn_name` —
недостаточное условие. Запрос из ТЗ §III.1 заменяется на запрос по множеству веществ.

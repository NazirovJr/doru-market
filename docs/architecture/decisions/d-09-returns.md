# D-09. Возвраты не описаны в ТЗ вовсе
**Решение:** вводится отдельная подсистема `order_returns` + state machine `return_status`.
Консервативный дефолт по законодательству РТ: **«обмен/возврат без причины» для медикаментов
не предлагается**; возврат возможен по причинам: брак, пересорт, повреждённая упаковка,
истёкший/близкий срок годности, недовоз. Возврат до вручения (`picked_up`) и после (`delivered`) —
разные ветви процесса.

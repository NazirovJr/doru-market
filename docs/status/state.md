## Известные долги

- `CartIdentityGuard` и `AnalyticsEventsIdentityGuard` сами проверяют JWT и не учитывают отзыв сессии.
- Телефон заявки сети: `PHONE_REGEX` контракта допускает номер без `+`, `PhoneNumber.parse` — нет.
- `VITE_API_BASE_URL` не пробрасывается в сборку web через compose.
- Обработчики domain-events delivery/inventory полагаются на собственную идемпотентность (at-least-once).
- `docs/api/openapi.json` ни разу не закоммичен, хотя его ждёт `openapi:check`.
